# Security Policy

## Supported Versions

The project is in pre-release planning. Security fixes will target the main development branch until stable releases are available.

## Reporting a Vulnerability

Please report vulnerabilities privately.

Preferred contact method:
- Open a private security advisory on GitHub (when enabled)

Until private advisory tooling is enabled, contact maintainers directly and avoid public disclosure.

Include:
- Impact summary
- Reproduction steps
- Affected components
- Suggested mitigation if available

## Disclosure Process

1. Maintainers acknowledge receipt within 3 business days.
2. Maintainers triage severity and impact.
3. A fix and validation plan is prepared.
4. Coordinated disclosure is published after remediation.

## Scope

Primary security scope for OpenFoldr includes:
- Authentication and pairing
- TLS and trust validation
- Authorization and role checks
- Filesystem path sandboxing
- Transfer integrity and conflict safety
